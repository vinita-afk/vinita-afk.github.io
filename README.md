# Vinita Kashyap | AI & Full-Stack Developer Portfolio

🌐 **Live Website**: [https://vinita-afk.github.io](https://vinita-afk.github.io)

Modern, dynamic, glassmorphic developer portfolio showcasing projects in Machine Learning, IoT systems, Full-Stack development, and behavioral AI research.

---

## ✨ Features

- **Live GitHub REST API Integration**: Dynamic synchronization of public repository metrics, star counts, follower numbers, and language stats.
- **Glassmorphism & Ambient Glows**: Custom Tailwind CSS dark theme with smooth micro-interactions.
- **Full-Stack Project Showcase**: Highlights assistive IoT navigation devices, civic gamified platforms, and cognitive AI taxonomies.
- **Interactive UX**: One-click email copy with animated toast notifications, mobile-responsive collapsible navigation, and active scroll states.
- **100% Free Hosting**: Powered by GitHub Pages.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS (CDN), Custom CSS Glassmorphism
- **Icons & Typography**: Font Awesome 6, Google Fonts (Inter, Fira Code)
- **API**: GitHub REST API v3

---

## 🚀 Local Development

To view the portfolio locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/vinita-afk/vinita-afk.github.io.git
   ```
2. Open `index.html` in your browser:
   ```bash
   # On Windows
   start index.html
   ```
